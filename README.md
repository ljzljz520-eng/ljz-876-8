# 🧯 消防安全演练考试台

面向企业的消防安全培训—考核—演练闭环管理系统：员工完成 **灭火器使用、疏散路线、报警流程** 三门课程学习后参加 **线上测验**，演练当日 **线下签到**；未通过或缺训人员由系统 **自动纳入复训名单**，补考/补训/补签后自动解除。管理端可按 **楼层、部门、岗位** 查看完成情况。

## 快速开始

```bash
npm start          # 或 node server.js
# 打开 http://localhost:3000
```

零外部依赖（Node 内置 `http`/`crypto` + JSON 文件持久化，数据保存在 `data/db.json`）。
前端使用 Vue3 / Element Plus / ECharts（CDN 引入，需联网加载）。

## 业务闭环

```
三门课程学习完成 → 线上测验(10题,80分合格) → 演练现场签到 → 综合判定「合格」
                        │ 未通过                         │ 缺训
                        └──────────► 自动进入复训名单 ◄───┘
                                        │
                 补考通过 / 补训补签后自动解除（管理员可手动闭环）
```

**合格判定**：三门课全部学完 且 最近一次考试 ≥ 合格线 且 现场已签到。

## 功能清单

### 员工端
- 工号登录，查看本人被分配的演练批次（按所在楼层自动分配）
- 三门图文课程学习，逐课记录学时；全部完成才解锁测验
- 线上测验：灭火器 4 题 + 疏散 3 题 + 报警 3 题，服务端组卷随机抽题、服务端判分
- 交卷即时出分、逐题解析；未达线自动进入复训名单，可参加补考
- 查看线下签到状态与综合合格进度

### 管理端
- **演练总览**：各批次应参加/完成学习/测验通过/签到/合格/待复训人数与合格率
- **完成情况**：按楼层、部门、岗位 + 姓名/工号筛选；楼层/部门合格率柱状图、岗位饼图、完成漏斗；人员明细表；CSV 导出
- **线下签到台**：工号/姓名签到、重复签到拦截、签到流水、撤销纠错、补签自动解除复训
- **复训名单**：自动入册原因（测验未通过/演练缺训/学习未完成）、状态跟踪、办理闭环
- **考试记录**：全部交卷记录（含补考次数）
- **演练后结算**：一键同步，缺训/未过人员自动进入复训名单
- 角色权限：签到员仅可签到与只读查看，重置/撤销/闭环等写操作仅限管理员

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/login | 登录（role: emp/admin） |
| GET | /api/me | 员工首页：本人与各批次进度 |
| GET | /api/me/progress?sessionId= | 某批次详细进度 |
| POST | /api/me/learn | 课程学习打卡 |
| GET | /api/me/exam/paper?sessionId= | 组卷（随机抽题） |
| POST | /api/me/exam/submit | 交卷（服务端判分，未过自动入复训） |
| GET | /api/admin/overview | 各批次总览 |
| GET | /api/admin/stats?sessionId=&floor=&deptId=&position= | 分组统计 |
| POST | /api/admin/checkin | 现场签到 |
| POST | /api/admin/checkin/undo | 撤销签到 |
| GET | /api/admin/retrain?status=&sessionId= | 复训名单 |
| POST | /api/admin/retrain/close | 办理复训闭环 |
| POST | /api/admin/session/sync-retrain | 演练后结算自动入册 |
| GET | /api/admin/exams | 考试记录 |
| POST | /api/admin/reset-demo | 重置演示数据 |

## 目录结构

```
server.js          HTTP 服务 + 路由 + 统计聚合
logic.js           业务逻辑（状态计算/判分/签到/复训状态机）
store.js           JSON 持久化 + 种子数据（员工/课程/题库/批次/历史记录）
public/
  index.html       门户首页
  employee.html    员工端 SPA
  admin.html       管理端/签到台 SPA
  js/api.js        fetch 封装
data/db.json       运行期数据（自动生成；管理端可一键重置）
```
